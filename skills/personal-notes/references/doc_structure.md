# Personal Notes Document Structure

## Document Organization

```markdown
# Personal Notes — [User Name]

## 📝 Daily Notes
**2024-01-15 09:30** — Reviewed project requirements with team
**2024-01-15 14:20** — Need to follow up on API documentation — [问题]

## 📅 Meetings
**2024-01-15 10:00**
Weekly sync with engineering team
- [ ] Action: Update deployment schedule
- [ ] Action: Review security checklist

## 💡 Thinking
**2024-01-15 16:45** — Idea: Automate weekly report generation
**2024-01-15 20:30** — Consider using vector DB for note search

## ✅ To-Do Items
**2024-01-15 09:00** — [ ] Finish API documentation review
**2024-01-15 14:30** — [ ] Prepare for tomorrow's presentation

## 📊 Weekly Summaries

### Week of 2024-01-08 ~ 2024-01-14
[Auto-generated summary]

### Week of 2024-01-15 ~ 2024-01-21
[Auto-generated summary]
```

## Marking Items as Pending

Add any of these markers to flag an item for daily reminders:
- `[ ]` or `☐` — Checkbox
- `待办` or `TODO` — Todo keyword
- `问题` or `问题` — Problem/issue flag

## Daily Reminder Format

The 21:00 reminder includes:
1. Total count of pending items
2. List of items (up to 10, oldest first)
3. Quick actions: "[Done]" to mark resolved

## Weekly Report Contents

Sunday 20:00 report includes:
1. Statistics (notes count, meetings, ideas, pending)
2. Meeting highlights
3. Key ideas/thoughts
4. Pending issues checklist
