# Quick Notes

快速记录笔记到 Obsidian，无需思考解决方案。

## 命令

| 命令 | 功能 | 存储位置 |
|------|------|----------|
| /todo | 记录待办事项 | 02-领域/临时记录/待办事项/active.md |
| /thinking | 记录思考灵感 | 02-领域/临时记录/思考灵感/ |
| /meeting | 记录会议内容 | 02-领域/临时记录/会议记录/ |

## 使用方式

```
/todo 完成技术方案文档
/thinking 关于用户流程优化的想法
/meeting 产品评审会，讨论新功能优先级
```

## 特点

- **/todo**: 直接记录待办，不进行思考或解决方案
- **/thinking**: 记录思考内容，不给出方案或建议
- **/meeting**: 记录会议内容，适当整理但不提供方案
