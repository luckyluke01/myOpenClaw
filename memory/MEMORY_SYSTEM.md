# Agent Memory System

为每个 Agent 配置三层记忆系统，自动学习用户偏好和工作模式。

## 目录结构

```
memory/
├── long-term/          # 长期记忆 (>30天)
│   ├── habits/         # 用户习惯
│   ├── concepts/      # 概念含义
│   ├── idioms/        # 习惯用语
│   └── preferences/   # 偏好设置
├── medium-term/       # 中期记忆 (5天)
│   ├── projects/      # 项目进展
│   ├── tasks/         # 任务详情
│   ├── contacts/     # 联系人/团队
│   └── context/       # 工作上下文
├── sessions/          # 会话记忆
│   ├── active/        # 当前会话
│   └── archive/       # 已结束会话归档
├── patterns/          # 模式识别
│   ├── frequency/     # 频率分析
│   ├── success/       # 成功模式
│   └── warnings/      # 注意事项
└── scripts/           # 记忆管理脚本
```

## 触发条件

### 长期记忆触发
- 同一概念出现 3+ 次
- 用户明确偏好或习惯
- 重要决策反复出现

### 中期记忆触发
- 新项目开始/结束
- 任务状态变化
- 人员变动
- 会议/讨论结果

### 会话记忆触发
- 每个会话结束时
- 重要结论达成时
- 任务分配时

## 更新频率

| 记忆层 | 更新频率 |
|--------|----------|
| 会话记忆 | 实时 |
| 中期记忆 | 每日 + 会话结束 |
| 长期记忆 | 每周 + 触发时 |

## 使用方式

在 Agent 工作时自动调用，无需手动触发。
